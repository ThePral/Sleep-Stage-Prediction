# Notebook index

Earlier notebooks are preserved under `legacy/`:

- `legacy/baseline/01_dataset_exploration.ipynb` through `06_participant_split_model.ipynb`: original exploration, baseline training, evaluation and inference.
- `legacy/paper/sleep_stage_paper_*.ipynb`: earlier plotting and figure preparation.

Outputs and execution counts were retained. Only project-root/data-path
discovery was adjusted for the new locations. The maintained training pipeline
is under `src/`; its new SSL/cross-attention/BiLSTM recipes are documented in
[the implementation guide](../docs/SLEEPEDF_BILSTM.md). The older notebooks contain training/export cells that can
write legacy model/results paths, so their historical outputs should not be
treated as current research results or regenerated by running every cell.

Open a notebook with its working directory anywhere inside this checkout.
Its root discovery finds the ancestor containing `src/` and `README.md` and
uses that root for imports and data paths. The raw/feature/model artifacts
the notebooks reference remain in their original locations.
